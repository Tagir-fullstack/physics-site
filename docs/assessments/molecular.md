# Молекулярная физика

- Студент: `/assessment/molecular` (также в каталоге контрольных срезов).
- Администратор: `/admin/assessment-monitor/molecular`, выбор времени входа, старта, длительности и открытия разбора — существующая панель сеансов.
- По умолчанию 50 минут. Уже сохранённые сеансы/попытки не меняются.
- Первичная инициализация нового периода (аддитивная, идемпотентная):
  `node --env-file=.env.local scripts/setup-molecular.mjs`
- Никакие сеансы и публикации решений скрипт не назначает. Пока преподаватель не задаст время открытия, решения закрыты.

## Состав и оценивание

| № | Тема | Баллы | Основание: предоставленные страницы |
|---|---|---|---|
| 1–2 | Два разных типа из шести: относительная молекулярная масса; количество вещества; масса газа; число частиц; масса частицы; нормальный объём | по 0,3 | 8.1–8.10 |
| 3 | Концентрация по числу молекул и объёму | 0,5 | 9.1–9.3 |
| 4 | Масса газа по p, V, T и молярной массе | 0,5 | 8.27, 9.14 |
| 5 | Изобарное нагревание: повышение температуры по относительному увеличению объёма | 0,5 | 8.21, обратная постановка |
| 6 | Средняя квадратичная скорость | 0,5 | 9.25–9.28 |
| 7 | Плотность смеси N₂ и He по массовой доле | 0,7 | 8.42–8.43, индивидуальная постановка |
| 8 | Доля диссоциировавших двухатомных молекул по изменению p и T при постоянном V | 0,7 | 8.15, 9.11, обратная постановка |

Всего 4 балла. По одному числовому полю в задаче. Нужная единица указана рядом; для больших/малых величин вводится коэффициент при явно заданной степени десяти. R = 8,31 Дж/(моль·К), Nₐ = 6,02·10²³ моль⁻¹, Vₘ = 22,4 л/моль при нормальных условиях. Для чистого газа учебные целочисленные молярные массы указаны в условии, где нужны.

Допуск max(0,005; 1% от правильного ответа), ввод не менее трёх значащих цифр. Запятая и точка принимаются. Пустой/нечисловой ответ не засчитывается. Штрафная политика та же, что в рубежном срезе; мониторинг масштабирует итог на 4 балла.

## Варианты и приватность

Сервер создаёт индивидуальные числовые условия; первые два типа обязательно различны. Полный отпечаток условий уникален через существующий глобальный индекс БД, при конфликте генерация повторяется. Повторный вход получает сохранённую попытку. Шесть типов первых задач — банк, поэтому отдельная тема может повторяться у разных студентов, но полный вариант не повторяется.

Публичная выдача содержит только условия, стоимость и поля. Правильные значения и формулы вычисляются на сервере; они открываются студенту только после сдачи и наступления назначенного времени. До открытия выдаётся только суммарная оценка. Разбор администратора защищён существующей проверкой роли. PRO сам по себе не даёт право предварительного просмотра экзамена или перезапуска.
